*agent-cli.nvim*  Neovim plugin for Pi Agent

==============================================================================
1. Intro

Minimal plugin integrating Pi Agent as an interactive terminal powered by snacks.nvim.

Requirements: Neovim >= 0.10, snacks.nvim, and the `pi` CLI command.

==============================================================================
2. Setup                                 *agent-cli.nvim-setup*

>lua
require("agent-cli").setup({
  commands = { "pi" },
  focus_on_sel = true,
})
<

Options: ~
  commands      - Agent CLI commands (default: { "pi" }). With more than one,
                  |:AgentOpen| shows a picker (|vim.ui.select()|)
  focus_on_sel  - Focus terminal after sending selection (default: true)
  terminal      - snacks terminal options (see |snacks-terminal|)

terminal options: ~
  .interactive  - Enable interactive mode (default: true)
  .win.position - Docked position: "right" (default), "left", "top", "bottom"
  .win.width    - Width as fraction of editor (default: 0.30)
  .win.height   - Height as fraction of editor (default: 0)
  .win.relative - Coordinate system: "editor" (default), "win", "cursor"

==============================================================================
3. Commands                              *agent-cli.nvim-commands*

:AgentOpen [cmd]                               *:AgentOpen*
        Open an agent CLI terminal. Without [cmd], opens the only entry
        in `commands`, or shows a picker when there are several. Focuses the
        terminal if that command is already running. When another
        agent terminal is already open, asks where to place the new one
        relative to the current (or last used) agent terminal: left, right,
        split bottom or split top.

:AgentSendSel                                  *:AgentSendSel*
        Send visual selection to Pi Agent (visual mode only). With several
        agent terminals open, shows a picker to choose the target.

:AgentSendFile                                 *:AgentSendFile*
        Send the current file reference to Pi Agent. With several agent
        terminals open, shows a picker to choose the target.

==============================================================================
4. Keys                                  *agent-cli.nvim-keys*

<leader>ap     Open Pi Agent (normal mode)
<leader>ap     Send selection to Pi Agent (visual mode)
